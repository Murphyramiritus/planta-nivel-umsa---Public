# Planta de Nivel - UMSA

Repositorio de la escuadra de la planta de nivel de liquido.
Asignaturas concurrentes: ETN-902, ETN-1034, ETN-1000.

## Estructura

- `documentacion/planos_isa/` - planos P&ID y electricos (.dwg y .pdf)
- `documentacion/manuales_inversa/` - fichas tecnicas del Laboratorio 1
- `database/scripts/` - modelo E-R y scripts SQL (ETN-1000)
- `middleware/` - programas de comunicacion (Modbus, dashboard)
- `historico/` - material de semestres anteriores

Los videos e instaladores no se versionan: estan en Google Drive.
Ver `historico/README.md`.
